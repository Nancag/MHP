# MKHP 第二阶段进度与验收

日期：2026-10-24。

本阶段仅获得本地开发与离线测试权限。没有运行真实商品采集、保存实际 API 密钥、调用真实生成模型、安装依赖、启动业务服务或迁移现有业务数据库。

## 已实现的代码

- 双语介绍：目标语言和文本模型都由用户明确选择，没有默认模型或默认语言。当前支持16种目标语言，每段正文、标题、卖点同时保存对应中文翻译。
- 生图提示词：将自然语言要求与识别字段一并交给所选文本模型，返回英文画面提示词、中文译文、负面提示词及待核对事项。提示词可传入 PTMD 创作要求，不会自动发起生图。
- 模型仅从服务端环境变量读取。模型调用前需确认发送商品字段、语言和创作要求及可能产生费用；不上传图片、Cookie或本地路径。
- 同一用户同一请求编号保持幂等；失败、超时、403和不合格响应不会自动重试。已保存失败状态提示上游可能已计费，服务重启不自动重发任务。
- 文案正文、语言、模型、创作要求、Token用量、任务状态及关联采集记录保存在 SQLite 的 `product_drafts` 表。当前只声明迁移，未修改现有业务库。
- Word与JSON均使用登录用户归属校验下载。Word为可编辑OOXML，按目标语言和中文逐段排列，附提示词与网页识别依据，无需新增应用依赖。
- 所有已识别图片链接支持分批归档。首次最多20张，之后可确认继续下载下一批；失败图片可单独确认重试，均保存到相同来源文件夹。每批沿用大小、时长及公网访问限制。
- 首页、全局样式、导航和主视觉保持原样。

## 配置与接口

仅创建了不含密钥的 `.env.text.example`。真实 `.env` 未修改。

- `MHP_TEXT_BASE_URL`：仅接受用户提供且已授权的 `https://api.openai-next.com/v1`，拒绝向其他地址或重定向地址发送密钥。
- `MHP_TEXT_API_KEY`：待用户另行授权保存后填写。
- `MHP_TEXT_MODELS`：待用户确认模型ID后填写允许选择的列表，逗号分隔；空值不会选择或调用任何默认模型。
- `MHP_TEXT_TOKEN_PARAMETER`：根据最终所选模型兼容性选择 `max_completion_tokens` 或 `max_tokens`。单次请求输出Token上限4096，没有自动切换协议。

新增 `/api/mkhp/ai-capabilities`、`/api/mkhp/drafts`、`/api/mkhp/drafts/{id}`、`/api/mkhp/drafts/{id}/export?format=docx|json`。

图片追加接口为 `/api/mkhp/imports/{id}/images`，要求明确的 `confirm_fetch`，可选择 `retry_failed`。图片来源只取自本人已保存的采集结果，不接受任意图片地址参数。
