# MHP 第三阶段：本地模型接入

本阶段已获授权：本地备份、代码改造、模拟 API 测试和前端构建。不包含真实密钥保存、真实模型调用、依赖安装、启动业务服务或现有业务数据库迁移。

## 已实现

- MKHP 文案按用户选择采用 Claude 原生 Messages 协议：`https://api.openai-next.com/v1/messages`，`x-api-key` 与 `anthropic-version: 2023-06-01`；后端配置示例指定 `claude-sonnet-4-6`。系统指令和严格的双语 JSON 结构在后端验证，截断、工具调用或未知事实字段不会作为成功文案采用。保留逐段中文翻译、Word 和 JSON 导出、历史及幂等请求。
- PTMD 使用选定的 `gpt-image-2`，提交到同一授权域名的 `/v1/images/edits`，multipart 的 `image[]` 顺序为本页商品原图、最多2张风格参考图。固定原生尺寸1536×2048，独立生成每页，再本地排入准确文案并导出长边1200/2000像素；不会恢复抠图。
- 生图质量 low/medium/high 由用户在界面自行选择，不默认。界面说明成本、细节和耗时取舍；真实渠道费用未核实。
- AI 生成及单页重生成需确认发送图片与创作要求、张数和另计上游费用；后端要求 `confirm_send`。缺少质量、确认或配置时不会预留MHP额度。
- 复用现有本地保存、SQLite元数据、历史、审核、导出、用户隔离及额度流程。相同请求ID不会重复创建或调用；一页失败停止其余页；支持取消未提交任务。失败退还MHP额度不表示上游退款。
- 只接受内嵌 `b64_json` 图片响应，校验大小、图片格式、像素数及帧数。不下载服务商返回的未知网址；若该渠道仅支持URL响应，将明确报兼容性错误，再单独确认适配方案。
- 密钥仅从后端环境读取；没有修改真实 `.env`，没有把密钥放入前端。拒绝其它域名、自动跳转、自动重试、自动切换模型或旧千问接口回退。
- 首页及主视觉未修改；只调整MKHP/PTMD工作流程。MKHP提示词入口打开套图工作台，允许生成1张或多张。
