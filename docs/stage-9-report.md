## 二、失败项

| 优先级 | 失败项 | 复现结果与原因 |
|---|---|---|
| P0 | 商品主体合成未实现，商品保真失败 | 已传 cutout_id，但后台只下载模型图片，没有读取抠图并合成。实际结果商品结构明显改变。另用“红色商品抠图＋纯蓝背景”做受控测试，保存结果完全没有红色商品。不能把当前输出称为原商品保真合成图。 |
| P1 | 分辨率和比例未生效 | UI 选 16:9、1200，两次结果都是 1024×1024。前端仅把值放进 params/提示词，没有发送 size，后端使用默认尺寸。2000/4000/8K 选项也没有对应实现。 |
| P1 | 历史结果无法正常打开预览 | 点击历史后 selectedProduct 被清空，而 Canvas 的外层要求 product 存在，因此显示“请选择商品”而不是生成图；商品变化的 watcher 还会重置标签。历史列表和数据库保存通过，历史结果预览失败。 |
| P1 | 重复请求没有后端幂等保护 | 同样的抠图请求执行两次推理；同样的生图请求提交两次任务。该项使用替身模型测试，未重复消耗真实免费生图额度。重新生成按钮也没有绑定 generating 禁用条件。 |
| P1 | 没有进行中任务取消机制 | 未找到生成取消控件，`POST /api/generations/{id}/cancel` 返回 404。取消文件选择通过，不代表能取消已提交的生成或抠图任务。 |
| P1 | 持续数据库故障使后台任务停留 pending | 模拟 update_generation 持续报 SQLite 错误，后台异常处理再次写数据库仍失败，异常逃逸，记录保持 pending。 |
| P2 | 英文自动 Prompt 降级错误 | 模拟文本模型超时，选择 en 后本地模板仍返回中文；中英文降级文本均遗漏所选比例和分辨率。真实 qwen-turbo 调用未验证。 |
| P2 | 切换界面语言丢失选项语义 | 先选“英语”，再切换 English UI，语言选项重置为 Chinese。参数使用翻译后的显示文本存值，无法稳定映射。 |
| P2 | 英文历史场景筛选失效 | 两条中文“客厅”历史存在，英文按 Living room 筛选返回 0 条，显示文本被直接用作数据库筛选值。 |
| P2 | 网络失败提示不准确 | 真正断网时显示“暂无商品图片（API: /api/assets）”，没有明确说明网络连接失败。没有 traceback，但普通用户难以理解原因。 |
| P2 | 部分异常暴露内部路径 | 模拟生成文件保存失败后，数据库 error 和任务查询响应包含原始 OSError 中的文件路径。需要统一面向用户的错误信息。 |
| P2 | 下载格式与扩展名缺少一致性校验 | 模拟上游返回 JPEG，仍保存为 `.png` 并按 image/png 提供；实际两次万相输出恰好为 PNG，因此没有触发此边界。 |
| P2 | 损坏生成下载残留文件 | 模拟上游图片损坏，Image.open 报错，但已写出的坏文件没有清理。 |

## 三、待优化项

1. 先完成“生成背景 → 按原透明主体合成 → 保存最终图”的真实实现，再用主体轮廓、比例、颜色、结构逐项复验。保真不能只靠 Prompt 指令。
2. 对 UI 比例/分辨率建立显式映射、后端白名单和实际尺寸校验；超出所用模型能力的分辨率应说明限制或明确后处理方案。
3. 修复历史视图独立于当前素材的预览逻辑；结果信息区应显示结果尺寸和格式，而不是一直显示原图信息。
4. 引入请求幂等标识及并发保护；重新生成期间禁用重复操作。取消应明确“停止前端等待”还是“撤销上游任务”，不可混淆。
5. 参数与历史存稳定内部值，翻译仅用于显示；补齐英文错误、提示、工具提示，修复英文降级模板。
6. 下载先验证格式与像素，再原子保存；文件和数据库失败时进行一致性清理。为持续数据库故障及服务重启后的任务状态设计恢复策略。
7. 若继续验证自动 Prompt，需要先确认 qwen-turbo 的可用免费额度与用完即停，再做一次真实响应验收；当前只有模拟和本地降级测试。
8. 在实体手机及 Safari/Android Chrome 上补验文件选择、长任务、下载和键盘遮挡。当前结果仅覆盖 Edge 手机视口模拟。

## 四、风险项

- **商品失真风险：** 当前生成图不复用原商品像素，实际已出现主体结构改变，不能用于声称保真的商品图流程。
- **额度与重复提交风险：** 当前业务无幂等控制，普通重复请求可提交多次上游任务。本次隔离测试额外限制到两次，不代表产品已有同样保护。
- **费用信息不可信：** 完成任务后代码把 cost_usd 固定写为 0.16，这不是阿里云账单，也不是本次测试实际费用。本次按照用户确认的免费额度执行，没有独立读取云账单。
- **邮件容量限制：** 当前 SMTP 为全站每天最多 10 次发送。邮箱开放给所有用户不等于发送能力无限，达到上限后新用户无法取得验证码。
- **任务状态与存储风险：** 已复现永久数据库失败后任务保持 pending、坏文件残留，以及原始路径进入用户响应。
- **验收范围限制：** qwen-turbo 在线可用性、实体手机兼容性和实际高并发未验证，不能把本报告解释为这些项目已通过。
