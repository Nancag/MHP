# MHP 云端功能同步与工作空间发布

发布日期：2026-10-18，北京时间。版本：`2026.10.18-workspace.1`。

网站：https://118.178.92.58

## 已部署

1. 先同步当前已有应用功能，再发布新增功能。保留云端 .env、数据库、用户图片、四个 ONNX 模型、独立 HTTPS 容器和 Windows 下载页面。内层网页服务升级至现有 Caddy 2.11 镜像。
2. 工作台支持删除选中商品原图和参考图。删除移动文件至回收站，素材列表和原图接口不再返回该图；保留已有生成结果。设置中心提供恢复。正在生成或抠图时拒绝冲突删除。回收站当前没有自动清空机制。
3. 前端生成参数、套图参数和导出选择仅保留1200/2000。后端拒绝4K/8K，能力接口也只公布这两档。既有大图文件没有清除。
4. MKHP 从占位入口改为市场调研与竞品分析：项目新增、编辑、历史、删除；竞品名称、来源、日期、价格、评分、评价数、优劣势；同币种价格最小值、最大值、均值、中位值、自身价格对比；结论记录；JSON导入导出和CSV导出。当前采集数据由用户录入，不抓取平台实时数据，不推算销量。
5. 个人模板库支持保存当前工作台设置、名称/描述检索、套用及删除。模板保存参数和文案，去除素材引用，套用后重选素材。按账号隔离。
6. 独立设置中心支持主题、语言、默认抠图模型、边缘去底色、默认尺寸，以及版本、服务配置状态、模型安装状态、图片回收站。偏好保存在服务器账号下。
7. 管理员自动备份和恢复入口。管理员为用户指定的登录邮箱；普通账号无权访问整站备份。恢复必须输入“恢复整站”确认，会退出旧会话；恢复前自动创建安全快照。
8. 本地已有的生图API配置通过加密SSH私密同步，未打印或包含在代码包中。按用户选择，没有发起真实生图验收。

## 自动备份

- 每天北京时间03:30，由主机systemd执行，保留最近7份普通备份，恢复前安全快照单独保留。
- 管理员可在“设置 → 自动备份与整站恢复”手动备份、查看状态、选择备份恢复。
- 包含应用代码、前端、部署配置、私密环境配置、业务数据库及图片。排除可重新安装的模型和缓存；恢复时保留当前模型目录。
- 备份位于服务器 `/opt/mhp-backups/automatic`，只允许主机管理员访问。它是同机备份，未配置异地存储。备份和恢复会短暂停止业务容器。
- 主机服务：`mhp-operations.timer`、`mhp-nightly-backup.timer`。备份作业与恢复作业使用文件锁串行运行。
- 恢复校验SHA256、归档路径、SQLite完整性；清除旧验证码和会话；恢复对应镜像。恢复失败时尝试回到恢复前快照。

## 使用入口与范围

- 电脑刷新页面可按Ctrl+F5；手机关闭旧标签后重新打开HTTPS网址。
- 图片删除：PTMD工作台选择商品原图，再点“删除选中的原图”；选中的参考图也有删除按钮。
- 图片恢复：设置 → 图片回收站。
- 模板：工作台左侧“模板”保存当前创作设置；首页侧栏“模板库”搜索并套用。
- MKHP：首页“MKHP”卡片或侧栏“市场调研”。
- 备份恢复：用指定管理员邮箱登录后进入设置中心；恢复时填写确认文字。

本次没有启用短信、支付或到期提醒等未申请/未配置的服务，没有做付费真实生图调用，也没有宣称完成供应商画质或费用验收。抠图推理仍是CPU路径，本次没有承诺其速度改善。
