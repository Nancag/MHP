## 通过项

| 原失败项 | 修复与验证 |
|---|---|
| 未合成原商品 | 后台下载背景后读取对应透明抠图，裁掉透明留白，保持主体宽高比及 Alpha，再合成并保存。发给模型的指令要求只生成空背景。已验证红色主体＋蓝色背景、半透明边缘混合，以及真实商品抠图进入最终图片。 |
| 比例、尺寸无效 | 后端根据稳定参数计算真实导出尺寸，模型请求尺寸与最终导出尺寸分别处理。支持五种比例及长边 1200/2000/4000；16:9、1200 实际导出 1200×675；另实际检查 4000×2250 PNG。超过模型请求尺寸的背景经本地放大后合成，界面明确说明。**8K 已从选项移除，接口也拒绝该值。** |
| 历史预览为空 | 生成结果预览独立于当前商品选择；移除会重置标签的监听；结果信息显示实际生成尺寸、格式及文件大小。浏览器实际打开历史成功。 |
| 重复请求 | SQLite 请求登记表按用户、操作及请求编号去重；旧客户端无编号时按请求内容去重。处理中重复返回 409，已登记请求返回原任务，失败/超时请求也不会自动再次提交上游。显式重新生成使用新编号。8 个并发请求仅一个取得执行权；UI 快速双击重新生成只提交一次。 |
| 无取消机制 | 新增所属用户的生成取消接口与按钮；完成状态只能从 pending 转移，避免取消后被后台覆盖。覆盖提交中取消、下载中取消、取消后丢弃结果。界面说明：**取消本地处理不能保证撤销上游任务或退还额度。** 本地抠图仍是同步推理，本轮未实现对 ONNX 推理的强制中断。 |
| 数据库故障后一直 pending | 无法写入任务结果时保存小型原子文件日志；数据库恢复后的查询/历史访问会补写终态。服务重启会恢复日志并把中断任务标为失败，不重新提交 AI。持续数据库故障、恢复、重启均通过隔离测试。 |
| 英文自动 Prompt 降级错误 | 本地模板支持中、英、俄语，包含比例和长边尺寸；兼容旧翻译标签。可选文本服务对超时及畸形响应也能降级。**当前工作台留空 Prompt 使用本地模板，不请求云端文本模型**，已更新输入提示。保留原有独立文本 Key 配置及服务实现。 |
| 切换语言丢失选项 | 参数保存稳定编码，翻译仅用于显示。先选英语再切换 English，仍选中 English。 |
| 英文历史筛选无结果 | 新记录保存稳定编码；查询兼容已有中文/英文标签。浏览器英文筛选及新旧混合记录测试通过。 |
| 断网提示含糊 | 显示网络连接失败及重试入口；新增前端请求等待上限，超时提示先查历史以避免重复提交。断网→提示→恢复→重试通过。 |

## 失败项、待优化项与风险

- **本轮规定的本地代码回归无剩余失败项。** 高分辨率通过本地放大实现；8K 未提供。
- 未追加任何真实万相或文本模型调用、收费 API、依赖安装或云端部署。之前确认的两次免费生图测试次数已使用，本轮不追加；改后的“真实 AI 背景→主体合成”视觉效果仍需另行确认可用额度后验收。
- 当前自动 Prompt 使用本地模板；云端文本模型的在线可用性、免费额度及输出质量仍未验收，不能宣称通过。
- 主体保持原拍摄角度，合成不自动匹配场景透视、光照或接触阴影；背景模型仍可能不完全遵从“空背景”指令。需用真实背景复核自然程度与重复物体。
- 手机覆盖为 Edge 的 390×844 视口模拟；实体手机、Safari 和长期高并发仍待测试。
- 恢复机制以当前单个后端进程的 MVP 为范围；部署多 worker 前需增加任务执行者协调。SQLite 和恢复日志所在磁盘同时不可写时无法保证持久化，需先恢复存储。
- 取消只终止本地后续处理。上游可能继续运行并消耗额度；本地 ONNX 推理没有强制中断。

按阶段要求在此停止，等待决定是否进入最终验收。
