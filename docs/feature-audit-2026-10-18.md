## 统计与边界

本轮使用项目 .venv 运行 unittest discover，127 项隔离测试通过，用时约 19 秒；隔离测试不能证明供应商真实可用、云端性能、真实邮件/支付或端到端业务成功。系统默认 Python 缺少项目依赖，最初测试未能完整运行，改用项目环境后通过。

## 已确认的关键差异

- 云端 API 曾通过健康检查，HTTP 页面响应 200；HTTPS 已执行 IP 验证及自动证书管理配置。应以当前浏览器证书与连通测试确认最终状态。
- 四个抠图模型已校验、解压并设置权限；用户已实际使用商品抠图并反馈慢。插画模型效果、长时间稳定性仍需实测。
- 本地相对最初上传包新增/变更了套图、海报、参考图和生成等模块，不能假定已经全部更新云端。其他聊天的更新、下载页发布记录不能替代当前服务器版本对照。
- 前次服务器配置截图中生图 Key 为空，本聊天未确认后续成功填写和真实调用；不列出授权码或 Key。
- 单图生成目标尺寸可到4000，但基础模型调用尺寸受代码映射限制；套图8192导出可为插值放大。导出尺寸不等于原生生成清晰度。
- Windows 客户端是云端网站容器，客户端安装本身不会同步服务器代码、模型或 Key。

## 建议新增及完善顺序

以下为结合现有代码的产品建议，不是竞品排名或新增开发承诺。

| 优先级 | 建议 | 价值及边界 |
|---|---|---|
| P0 | 本地/云端版本号与能力状态页 | 显示部署版本、模型存在、邮件与生图是否配置；不显示密钥 |
| P0 | 抠图分阶段耗时与快速/精细模式 | 先测排队、加载、推理、去底色、编码，再优化；质量取舍由用户选择 |
| P0 | 持久任务队列与排队提示 | 展示排队位置、运行阶段、完成通知，避免多人盲等；不能虚构准确百分比 |
| P0 | 生图服务连通验证与消费上限 | 区分未配置、余额不足、限流、失败；按任务预算，接供应商用量后再显示真实费用 |
| P0 | 自动备份及恢复演练 | 覆盖数据库、图片与必要配置，备份须受权限保护；验证可恢复 |
| P1 | 批量抠图与 ZIP 下载 | 当前有多文件上传，但没有完整的批量抠图任务与汇总下载 |
| P1 | 手动擦除/恢复蒙版、边缘修整 | 对自动抠图结果局部纠错，减少整张重跑 |
| P1 | 品牌模板及个人模板库 | 保存字体、配色、Logo、布局与参数，支持收藏、套用与版本管理 |
| P1 | 真实换背景导出及阴影 | 目前背景切换主要是预览；新增白底/色底/自定义背景导出和可调阴影 |
| P1 | 素材文件夹、搜索、标签及删除恢复 | 当前列表/生成筛选之外的完整素材管理 |
| P1 | 套图草稿保存与撤销/重做 | 任务结果已有记录；编辑中的草稿与操作历史需独立设计 |
| P2 | 平台尺寸与文案检查 | 为 Ozon、WB、Amazon 等提供规则配置；上线前按平台官方规则核实 |
| P2 | 管理员面板 | 用户、任务、失败率、服务配置状态、模型和费用管理 |
| P2 | 团队协作与审批 | 团队权限、共享素材、审核流、操作记录 |
| P2 | 更高算力或GPU推理 | 先有基准再选实例；当前后端明确指定 CPU，单换GPU机器不会自动启用GPU |
