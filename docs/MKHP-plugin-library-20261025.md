# MKHP 插件采集与 PTMD 示例图库（2026-10-25）

本轮按用户选定的方案完成本地实现：仅浏览器插件读取商品页面；图片文件保存在运行服务机器的磁盘，数据库保存用户、来源、文件夹及路径索引；Windows 辅助工具简化安装。没有部署、重启现有服务、修改正式业务数据或调用真实模型 API。

## 实际功能

- 插件升级至 0.3.0。支持淘宝、天猫带 `id` 的详情页，以及拼多多带 `goods_id` 的移动详情页；短链接须先由用户在浏览器正常跳转。其他网站尚不支持。
- 修正页面参数分隔符和多行尺寸提取，支持 JSON-LD 带单位数值、商品尺寸、包装/包裹尺寸及材质参数。优先保留页面可见规格价格，同时支持结构化最高报价。
- 导入预览完整列出商品名称、网页介绍、价格、最高价、币种、商品尺寸、包裹尺寸、材质、宽高深及重量。缺失字段留空，标为未识别，允许用户核实后补充。
- 只在用户确认后保存字段、下载所选图片。插件不读取 Cookie 或密码，不处理登录、验证码，也不自动调用模型。平台改版、未展开参数或商品页没有提供信息时，不能保证识别齐全。
- 停用新建静态网页采集接口：`POST /api/mkhp/imports` 返回 410；旧采集记录和已有图片继续保留。确认后的图片文件下载仍由后端完成。
- 同一用户的图片按商品来源网址分别归档；同商品链接的跟踪参数会被去掉，避免重复创建来源文件夹。不同商品编号分别创建文件夹，不跨账号共享。
- MKHP 可直接打开对应 PTMD 示例文件夹；单张图片可直接选入参考图。修复 PTMD 恢复旧套图时覆盖刚导入参考图的问题。从 MKHP 进入时仍加载生成能力配置，但不自动恢复旧套图。
- PTMD 保留创建个人文件夹、上传图片、跨文件夹最多选择两张参考图的功能。MKHP 和 PTMD 均可删除示例图，删除到回收站后两处同步隐藏，可在设置中心恢复。
- 图片使用本地文件＋数据库索引；服务器部署时“本地”指服务器磁盘。备份和迁移须同时保留数据库与图片目录。已有生成图片的保存机制继续使用项目原有文件存储。

## Windows 安装辅助工具

产物：`extensions/mhp-collector/MHP-Collector-Setup.exe`。

1. 在 MKHP 下载辅助工具并运行。
2. 点击“保存插件文件”，阅读用途并确认。
3. 点击“打开 Edge 管理页”并确认；在 Edge 手动开启开发人员模式。
4. 点击“加载解压缩的扩展”，粘贴工具提供的路径并确认。
5. 返回 MKHP 刷新，检测到插件 0.3.0 后开始采集。

工具将内嵌的八个插件文件保存在 `%LOCALAPPDATA%\MHP\Collector\0.3.0-<包校验标识>\mhp-collector`。不联网下载、不请求管理员权限、不改注册表、不关闭浏览器，也不替用户确认安装。文件目录须保留。重复运行核对现有文件后复用；内容被改或安装不完整时拒绝覆盖。新版使用独立目录，用户需手动移除旧扩展再加载新版。

辅助工具尚未签名；系统阻止运行时，可取消并使用 ZIP 手动安装，无需关闭系统防护。工具本轮只验证了编译和无界面的文件提取，未实际操作其窗口或在 Edge 中加载扩展。页面教程和独立教程均已更新，保留 ZIP 下载入口。

后端下载接口校验 EXE 与八个插件源文件的 SHA-256；缺失、过期或不一致时返回 503，防止下载旧辅助工具。更新插件后须运行 `python -B desktop/windows/build_collector.py` 重新构建。Docker 与发布脚本的文件清单已包含 EXE 和校验元数据；本轮未生成或上传新的发布压缩包。
