# MHP 官方：宠物加热垫（俄语）

模板 ID：`mhp-pet-heating-pad-ru-v1`。已于2026年10月25日按用户授权发布到现有公网 MHP，发布标识为 `2026.10.25-pet-template.1`。本次未调用真实收费 API。

## 使用流程

1. 在模板库选择“MHP 官方 · 宠物加热垫（俄语）”，点击“套用并开始策划”。套用只读取资料，不调用文案或生图服务。
2. 对照待核对清单填写真实名称、尺寸、材质、配件与功能，手动选择商品图、文案模型及7/8/9张。用大白话补充风格要求；俄语由这个专用模板确定。
3. 确认向文案服务商发送图片、事实和需求及可能费用，生成逐页俄语文案与中文对照。模板规则由后端按版本 ID 添加；待核实参数不会自动加入模型请求。
4. 逐页编辑标题、卖点、翻译和画面要求，核对后保存应用。不自动开始生图。
5. 自行选择制作方式。素材排版保留原图像素、不调用生图 API，但不能生成新场景、移除供应商文字或重设计真实照片；GPT Image 2 可重做场景与风格，有服务商费用，并需检查商品一致性。
6. 使用 GPT Image 2 时，自行选择质量及排字方式。程序排字可精确控制文案、受固定区域限制；模型排字自由度较高、可能出现外语或数字错误。确认费用后逐张调用既有生图流程。
7. 逐张核对商品、文案、配件和版式，再下载整套；重做单页另行确认收费。

## 模板内容

- 俄语、独立3:4、7/8/9张，不生成九宫格。
- 主图大品名、少字；已核实尺寸放在主图。第2–4页安排已核实功能，第5–6页展示真实细节，第7页安排使用场景，8/9页补不同场景或有依据的卖点。资料不足时使用可见外观、适用场景，不补造功能。
- 保留商品外形、颜色、结构和真实配件；换供应商风格，不虚构配件、安全功能或内部结构。
- 截图中的30×35cm、八档调温、4/8/12小时定时、防水阻燃、耐磨耐咬、过热断电、快速均匀升温、亲肤与节能均为待核对项，不是默认商品事实。
- 详情页中的可识别尺寸数值会在模型结果、人工保存、生图请求和单页重做时校验；生图指令明确禁止详情页尺寸标注。任意自然语言、模型画面和翻译仍需人工检查，这些检查不能证明商品宣传真实或保证模型完全遵循指令。
- 当前沿用原生1536×2048生图与长边1200/2000导出，不承诺8K。
