# MKHP 第一阶段变更（2026-10-24）

用户已选择：普通网页解析；图片存本地、SQLite 存元数据；后续双语文档采用 Word + JSON。

## 本地代码变更

- `/api/mkhp/imports`：提交公开商品网址、列表历史和轮询结果。请求必须包含 `confirm_fetch: true`。以后台任务解析静态 HTML，不执行网页脚本，不绕过登录、验证码或反爬。
- 商品字段来自 JSON-LD Product、Open Graph/meta 和可识别的参数表。保留来源证据；商品尺寸和包裹尺寸分开，缺失值不推断。多个商品对象采用第一个并提示核对。
- 图片存入 `data/uploads/references/<folder_id>/`，以 UUID 命名；SQLite 记录文件夹、用户、来源链接及采集结果。同用户同来源网址复用文件夹，不同网址分别创建。
- 每次最多识别200条图片链接、下载前20张；单张10MB、总下载60MB、任务时间预算90秒，拒绝非公网 DNS 地址及不受支持的图片类型。每次重定向重新验证并固定目标IP，HTTPS仍校验证书。
- `/api/library/folders`：创建/列出个人文件夹。`/api/library/folders/{id}/assets`：按文件夹分页读取参考图；`unfiled` 展示既有未分类参考图。
- PTMD 示例图库新增文件夹选择、创建、上传、选择参考图和移入回收站；删除不影响已有成品。现有图片预览和恢复流程支持子目录。
- MKHP 新增网址识别结果表、采集历史、图片来源及JSON导出，保留旧手工竞品调研。
- 数据库使用增量迁移，不删除旧表、旧图片或业务记录。正常启动会运行迁移；服务重启时将中断的采集标为失败，保留已存素材，不自动重新联网。
