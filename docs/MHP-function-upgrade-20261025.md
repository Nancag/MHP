## 成本公式与例子

运费 F=W×f；关税 T=用户选择的基数×t。

C=(进货价+F+T)/((1-货损率)×(1-2×佣金率))；售价P=2C。

佣金按最终售价计算，货损在佣金前摊销。佣金必须小于50%，货损必须小于100%。未填写的费用不自动认定为0；重量须填写包裹重量，不猜测网页重量的口径。

例：进货100元、包裹500g、运费0.02元/g、关税10%且基数仅进货价、佣金10%、货损5%，最终成本157.89元，售价315.78元。成本先四舍五入至分，售价严格等于显示成本两倍；分项加总可能存在分币差异。这是用户指定口径的经营测算，不含未录入费用，不自动换汇、不提供法定税率。
