# MHP 缺陷检查与修复记录

日期：2026-10-25。云端前端发布：`2026.10.25-bugfix.1`。

## 已修复的问题

| 问题 | 错误原因与影响 | 修复 |
| --- | --- | --- |
| 商品素材只能看到前100张 | 工作台固定请求第一页，没有后续页入口；更多素材无法选择 | 增加“加载更多商品素材”，累计显示、按ID去重，保留已有列表 |
| 生成历史只能看到前20条 | 历史接口有分页，界面未使用 | 增加“加载更多历史”，切换筛选时重置页码 |
| 默认输出尺寸没有用于套图 | 设置仅恢复旧单图参数，套图仍固定2000 | 新套图及重置使用保存的1200/2000设置；恢复已有任务保留任务尺寸 |
| 旧模板缺字段导致页面报错 | 对缺失的`pages`调用`map`，缺失`copy_lines`时又会调用`join`或`filter` | 统一生成完整、可编辑的套图草稿，补全页面、文案、张数及默认参数 |
| 制作期间可重置或切换历史 | 操作未禁用，可覆盖当前任务参数或批次，干扰结果展示和取消操作 | 禁用对应按钮，并在事件处理入口再次检查任务状态 |
| 密码登录后未读取账号偏好 | 只有页面初始化会读设置，登录成功回调未加载 | 登录后立即读取主题、语言；退出及会话失效时使旧请求失效并清理待应用模板等账号状态 |
| 历史加载失败被显示成“无记录” | 请求失败被吞掉并清空列表，用户无法区分网络错误与空历史 | 展示错误及重试入口，加载更多失败时保留已显示记录 |
| 快速切换历史筛选会显示旧结果 | 多个请求没有先后版本检查，慢的旧请求可覆盖新筛选 | 每次请求分配版本，仅当前请求能更新结果、错误和加载状态 |
| 异常主题或语言偏好可能破坏页面 | 初始化直接使用未校验的偏好，未知语言使翻译表为空 | 仅应用已支持的主题与语言，异常值沿用可用默认值 |

退出登录期间的慢偏好响应也加入回归，确保不会在退出后修改页面偏好。本轮没有改动模型调用、扣费或支付实现。

## 验证结果

- 修复前：6个核心浏览器场景均复现失败，包含旧模板`Cannot read properties of undefined (reading 'map')`异常。
- 冻结发布版本：81项离线后端回归通过、12项浏览器回归通过、Vite生产构建通过。
- 公网发布后：同样12项浏览器回归全部通过，业务API使用合成数据拦截；未写入真实账号或生成记录。
- 浏览器覆盖：101张素材翻页后选择、21条历史翻页后选择、默认尺寸与重置、恢复历史尺寸、两种旧模板缺字段、制作期间操作禁用、登录偏好、历史错误重试、筛选乱序、异常偏好及退出后的慢响应。
- 后端覆盖：注册登录及会话、额度、本地渲染审核与导出、模拟图片服务、浏览器采集与历史补采、素材和文件夹权限、模板、市场资料统计、下载、备份恢复及TLS处理。

审计中同时存在其他功能更新。旧采集入口已按新版本停用并返回410，插件已升级0.3.0，导致旧审计用例出现4项版本不匹配。保留原失败日志后，调整审计副本以验证新浏览器导入、保留历史的图片补采、停用接口不发出请求、当前插件包版本；没有恢复已停用功能。调整后的81项测试全部通过。

测试使用临时数据库、合成账号和模拟服务。未执行真实付费AI生成、支付、邮件发送或真实平台采集。这些结果覆盖上述流程，不代表所有潜在缺陷均已排除。
