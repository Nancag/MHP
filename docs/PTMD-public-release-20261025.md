# PTMD 公网发布记录：2026.10.25-ptmd-planner.3

初次发布按用户选择的 A 方案部署功能，未迁移文案密钥或模型配置，未调用真实文案或生图 API。2026-10-25 后续获得单独授权后，已通过加密 SSH 迁移文案配置，并完成一次合成资料的公网真实文案验收；当前大白话文案功能已启用。

## 已上线内容

- PTMD 商品图片、确认字段和大白话需求入口，支持生成俄语或英语套图策划并显示中文对照，逐页编辑、保存确认后应用到工作台。
- 主图最多四条文案，可保存示例中的三条卖点加尺寸；生图前由用户选择程序排字或模型图文及质量，逐张生成并验收。
- MKHP 仅使用插件采集，按商品网址分别归档，识别结果列表展示，PTMD 可定位来源文件夹、创建文件夹与删除示例图。
- Windows 插件安装辅助工具；图片继续采用文件保存、数据库索引。

初次 A 方案发布时，公网缺少文案密钥，大白话入口暂不能调用。后续已启用文案服务；生图配置保留，未进行新的收费生图测试。

## 后续文案配置启用与真实验收

按用户授权，仅迁移 `MHP_TEXT_BASE_URL`、`MHP_TEXT_MODELS`、`MHP_TEXT_API_KEY` 至服务器私有配置。先备份配置和数据库，再重建 API 容器；保留原 API 镜像、Web 容器、生图及其他配置。密钥未写入源码、命令参数或 GitHub。

在实际运行的公网 API 容器中，使用一张合成陶瓷杯图片、合成参数和一句大白话，通过同一策划服务调用 `claude-sonnet-4-6` 一次，返回 HTTP 200：俄语三页主图/细节/场景方案，7 组中文对照，结构校验通过，用时 24.66 秒；用量为 3400 输入 tokens、1378 输出 tokens，实际费用以服务商账单为准。

测试未发送用户商品资料、未操作正式业务数据库、未生图、未自动重试。首次验收脚本因 Windows/Linux 中文传输编码在调用前退出，确认服务器无请求记录后修复；真实模型请求总数仍为一次。公网首页和健康接口均为 HTTP 200，未登录访问策划能力接口仍为 HTTP 401。

此次为服务器服务层真实验收，未代替真实用户登录后的浏览器全流程验收。人工检查发现文案加入“优质”“舒适把手”等未提供依据的表述；结构校验不能证明商品事实，用户仍需逐页核对、编辑后应用，不得把模型推测直接作为商品卖点。

使用入口：PTMD 套图工作台 →「AI 帮我写需求与文案」→选择商品素材、填写确认参数及大白话需求→选择模型、语言和张数→核对并确认文案调用→编辑双语方案并保存应用。保存方案不会自动生图。
