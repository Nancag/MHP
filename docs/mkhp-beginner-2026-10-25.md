# MKHP 浏览器采集流程与新手教程

2026-10-25 已上线至 https://118.178.92.58 ，build 为 `2026.10.25-redesign.4`。公开教程：https://118.178.92.58/mhp-collector-guide.html 。

## 修改内容

移除 MKHP 中“商品网址”输入框、“读取网页并归档图片”按钮及其前端静态导入提交逻辑。静态解析适用于部分普通网页，但对淘宝等动态商品页不可靠，容易与浏览器插件流程混淆。新界面以浏览器插件采集为入口，不再要求用户在 MHP 粘贴商品链接。后端旧静态解析接口保留兼容，未删除数据库中的旧记录与图片。

保留采集历史、分页、字段来源、图片归档、失败图片重试、JSON 导出、PTMD 素材入口和文案功能。旧链接导入记录显示旧版标记和重新采集方法；完成状态用“已归档”表示，避免把任务完成误称为字段全部识别成功。成本测算面板移至采集历史与结果之后。

新增中文/英文六步教程，首次进入显示，可随时从“新手教程：从安装到采集”重新打开。原有用户也会看到一次新版教程。每次手动打开从第一步开始：

1. 下载、解压、加载插件并检查连接状态。
2. 在 Edge 地址栏右侧“扩展”菜单找到“MHP 商品采集助手”，附浏览器工具栏位置示意。
3. 同一浏览器保留一个 MHP 标签页，再打开目标商品详情页。
4. 在商品页打开插件，读取并发送至 MKHP 预览。
5. 自动带入来源网址，核对字段、选择图片并确认导入。
6. 查看采集历史，在 PTMD 示例图库使用归档素材。

教程明确浏览器扩展不在 MHP 网页内，也不能在手机或桌面客户端内部加载。下载 ZIP 不等于安装成功；检测提示仍由 v0.2.0 的实时握手产生。没有修改插件执行代码或权限，不要求现有 v0.2.0 用户重装。

独立教程页面同步更新，包含六步操作、扩展按钮示意、疑难排查和 English quick start，并适配手机与系统深浅色。教程及预览 dialog 显式跟随应用主题，修正传送到 body 后丢失深色变量的问题。

工作空间内部导航改为切换实际页面，使“模板库 → MKHP”时顶栏与左侧选择保持同步。
