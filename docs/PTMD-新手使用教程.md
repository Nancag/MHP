# PTMD 新手教程｜让商品图出道 📸

记住这条路线：**传图 → 选模式 → 填文案 → 生成 → 核对下载。**

**① 上传：请主角登场**

登录 MHP，进入 **PTMD**，在左侧点 **「上传主图」**，上传清晰的 JPG / PNG 商品照片，再点击选中。做详情页时，可以多传几张真实特写。

**② 选模式：今天怎么拍？**

- **素材排版（不调用AI）**：用已有照片制作，适合第一次练手；在右侧调整配色、裁切和文案。照片原有背景、文字会保留。
- **GPT Image 2**：按要求生成新画面，可选最多 2 张风格参考图；需要自行选择生成质量。选项不可用时，可先体验素材排版。

**③ 填内容：先让一张图出道**

右侧填写 **商品名称**，张数先选 **1**。文案语言选俄语或英语，并自行填入对应语言的 **图片标题**、**卖点文案**；主图卖点最多两条。

例如做马克杯：语言选 English，标题写 `CERAMIC MUG`；卖点按商品真实信息填写。

只想展示商品？勾选 **「无附加文字与装饰」**。需要调整尺寸或配色，展开 **「更多设置」**。

**④ 生成：开工！**

点底部 **「生成1张电商图」**。使用 AI 时，可在 **「画面要求」** 写：

> 浅色桌面，柔和自然光，画面简洁，保留商品真实颜色与结构，不添加配件。

素材排版模式的画面要求只作备注，需要通过素材、裁切和配色设置落实。

每张消耗 **1 个 MHP 额度**；AI 模式另有上游费用，提交前查看确认提示。重新生成也会再次消耗额度。

**⑤ 核对下载：你是最后的质检官 🔍**

点击成品，检查并勾选：**商品一致、文案无误、没有多余配件、版式符合要求**，再点 **「确认本页符合要求」**。

全部页面确认后，选择 **1200 / 2000 px**，点 **「下载已核对套图」**。

第一张满意了，再把张数增加到 **2–9 张**，逐页安排主图、卖点和细节。不满意的页面可用 **「重新生成本页」** 单独重做。
