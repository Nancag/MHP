# MHP 1.0.0 发布与使用说明

发布日期：2026-10-18（北京时间）。网站及 Windows 客户端版本均为1.0.0。

网站：https://118.178.92.58/

Windows安装版：https://118.178.92.58/downloads/windows/MHP-Setup-1.0.0-x64.exe

便携版：https://118.178.92.58/downloads/windows/MHP-1.0.0-x64-portable.zip

## 已完成

- Windows客户端显示当前版本，启动时和每15分钟检查云端更新。发现新版显示当前/新版本及说明，由用户选择是否下载和安装。下载校验完成后启动安装程序。相同或更低版本不会触发安装。
- 云端更新清单采用固定公钥RSA/SHA256签名，安装包验证SHA256与长度，下载地址限定为本站对应版本安装包。Windows安装包本身仍未做Authenticode发布者签名；更新发布签名与Windows代码签名是不同事项。
- 升级沿用MHP安装位置并替换原程序文件，账号WebView2资料保留。启动时扫描MHP受管更新缓存，仅清理低于当前版本、带正确标记、且没有链接跳转的目录；不扫描删除个人文件或用户照片。服务器旧版安装包/便携包已移出公开下载目录，并返回404。
- 主页增加1.0.0主题公告，在深色/浅色主题下展示PTMD、MKHP两款工作台的功能和版本。
- 主题和语言切换集中到设置中心；原主页/工作台顶部切换按钮移除。PTMD顶部提供设置入口。
- 新客户端向网页注入只读客户端标记，主页及登录框隐藏“下载客户端”。浏览器网页仍可下载安装包。客户端下载和账号图片下载彼此独立。
- MKHP首页卡片和侧栏连接真实市场调研工作台；云端实际验证调研保存、竞品价格统计、CSV导出、删除。数据由用户采集录入，有来源与日期；当前没有平台实时抓取功能。
- 提示词推荐选项去重：已在输入框中的选项禁用，再次点击不会重复插入；移除该段后可再次选择。手写提示词不会被自动改写。
- 注册和登录分开。注册时验证码验证邮箱、设置密码；之后使用密码登录，不再索取验证码。默认记住设备，使用HttpOnly持久会话并在访问时续期；本地邮箱标记只用于预填，不作为登录凭证。
- 旧账号保持原有ID、图片与额度。已经登录的设备可在设置中首次设置密码。旧设备全部退出且尚无密码时，可通过注册页的一次邮箱验证完成密码绑定，不创建重复账号。旧验证码登录接口在云端关闭，仅保留内部显式开启的兼容测试开关。
- 主动退出、清理浏览器资料、恢复整站或会话失效后需要密码登录；不会仅凭本地存在邮箱记录授予账户访问。
- 新密码采用独立盐和PBKDF2-HMAC-SHA256（600000次）存储，登录有限速，修改密码使其他设备会话失效。

## 旧版用户操作

0.1.0没有更新检查模块，需要手动下载安装1.0.0一次。安装前关闭旧客户端。以后新版本通过客户端检查和提示安装。

已有账号建议先在已登录设备进入“设置 → 账号登录与设备”，设置一次登录密码。原有账户数据保留。

更新发布私钥仅在本机 `data/windows-client/private/update-signing.pem`，未上传服务器、未进入安装包。维护人员应私密保管和备份；以后发布必须使用同一密钥，不能随意替换。
