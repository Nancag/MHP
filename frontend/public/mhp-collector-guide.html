从这里开始采集商品。

浏览器打开商品页 → 点击浏览器插件 → 回到 MHP 核对并导入

无需在 MHP 粘贴商品链接。插件自动携带商品来源网址。原“读取网页并归档图片”入口已移除，已有采集历史和图片保留。

请使用电脑端 Edge 浏览器。手机和桌面客户端内部不能加载本浏览器插件；可以用 Edge 打开 MHP 网页进行采集。

1. 安装一次插件

  1. Windows 用户点击“下载 Windows 安装辅助工具”，运行下载的 MHP-Collector-Setup.exe。
  2. 在工具中点击“保存插件文件”，阅读用途并确认。插件会保存到你的本机应用数据目录，无需手动解压。
  3. 点击“打开 Edge 管理页”并确认，在 Edge 中开启“开发人员模式”，点击“加载解压缩的扩展”。
  4. 点击工具中的“复制加载路径”，把路径粘贴到 Edge 的目录选择框中并确认。
  5. 确认“MHP 商品采集助手”版本为 0.3.0 且已启用。返回 MKHP 刷新并检测连接。

工具不会绕过 Edge 确认、修改注册表或关闭浏览器。保存的插件文件夹必须保留。辅助工具尚未签名；遇到系统拦截时可取消并选择 ZIP 手动安装，无需关闭系统防护。

使用 ZIP 手动安装 / 更新已有插件

下载并解压 ZIP，在 Edge 地址栏输入 edge://extensions，开启开发人员模式，点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。旧版用户可自行备份并更新原目录、点击“重新加载”；使用辅助工具会创建新目录，需在 Edge 删除旧扩展后加载新版，避免重复安装。

2. “MHP 商品采集助手”在哪里点击？

在 Edge 浏览器右上角，不在 MHP 网页里面。点击地址栏右侧的“扩展”（通常是拼图图标），在列表中点击“MHP 商品采集助手”。可以将它固定或显示在工具栏中。

3. 准备两个网页标签

  1. 在同一个 Edge 中打开 MHP，登录后进入左侧 MKHP，保留这一个 MHP 标签页。
  2. 另开目标商品详情页，自行登录、处理验证码、选择规格、展开商品参数，等信息加载完成。

支持淘宝 item.taobao.com、天猫 detail.tmall.com 含 id 的详情页；以及拼多多 mobile.yangkeduo.com、mobile.pinduoduo.com 含 goods_id 的详情页。短链接请先正常跳转到商品详情。

商品链接在浏览器地址栏打开。不要在 MHP 寻找链接输入框，也不要同时打开多个 MHP 标签页。

4. 在商品页采集

  1. 让商品详情页成为当前标签页。
  2. 从浏览器右上角“扩展”菜单打开 MHP 商品采集助手。
  3. 点击插件弹窗里的 “读取当前商品页”。
  4. 核对候选名称、价格和图片数量，点击 “发送到已打开的 MKHP 预览”。

这两个按钮位于浏览器插件弹窗中。读取只获取候选资料，不会自动调用 AI 或下载图片。

5. 回到 MHP 核对并确认导入

插件会切回 MHP，打开“核对浏览器采集内容”对话框。检查并编辑字段，逐张勾选最多20张图片，然后点击 “确认导入所选内容”。来源网址自动带入，不需要再次输入。

候选图可能包括推荐商品或促销图，请人工筛选。缺失尺寸、材质须核实后补充。勾选显示缩略图会让浏览器访问图片网址；确认导入后，MHP 后端才下载所选图片并归档。

6. 查看采集结果，在 PTMD 中使用

导入记录出现在 MKHP 下方 “采集历史”。点开检查字段、来源和归档图片；图片下载失败会列出原因，核实后再决定是否重试。点击 “前往此商品的 PTMD 示例文件夹”，直接定位对应来源；也可在单张图片下点击“用于 PTMD 示例图”，将其选入生成参考。可在 MKHP 或 PTMD 删除示例图，删除后进入可恢复的回收站。

已有旧版链接导入记录仍可查看，会标注旧版来源。需要重新采集时，请按上述浏览器插件流程操作。

常见问题

已经安装，为什么显示“未检测到”？

确认插件 v0.3.0 已启用、允许访问当前 MHP 网址，MHP 与商品页在同一个 Edge，刷新 MHP 后点击“重新检测”。手机或客户端内部无法使用浏览器扩展。未检测到也可能是旧版或页面尚未刷新，不等于一定没安装。

为什么点击插件仍读不到商品？

当前标签必须是支持的商品详情页，不是登录、验证、订单或首页。自行完成验证并展开参数后再采集。平台改版或页面未提供某字段时仍可能无法识别；安装成功只证明插件与页面连接，不能保证每个商品都能读取。

为什么预览没有送到 MHP？

确保同一浏览器只保留一个 MHP 标签页，已登录并进入 MKHP。不要把商品页开在另一种浏览器或另一台设备。返回商品页重新打开插件并发送。

会上传密码或自动花费 AI 额度吗？

插件不读取密码或 Cookie，不采集订单与支付页面。确认导入后才保存商品字段、来源和所选图片；生成文案或 AI 图片属于后续独立操作。

English quick start
  1. On Windows, run the setup helper and approve saving the extension files. Open Edge management, enable Developer mode, choose Load unpacked and paste the folder path from the helper. Alternatively, extract the ZIP and load the folder containing manifest.json.
  2. The extension is in Edge’s Extensions menu beside the address bar, not inside the MHP webpage. Click MHP 商品采集助手. Version 0.3.0 must be enabled.
  3. Keep one signed-in MHP tab open on MKHP. In a second tab, open a supported product detail page. Sign in, choose the variant and expand its specifications.
  4. With the product page active, open the extension and click 读取当前商品页, then 发送到已打开的 MKHP 预览.
  5. Review the fields in MHP, select up to 20 images and confirm the import. The source URL is included automatically; there is no product URL form in MHP.
  6. Open Collection history to inspect the result, then select the archived folder in the PTMD reference library. The extension does not work inside the desktop client or on phones.
