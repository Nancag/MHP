# Noto Sans

Unmodified Noto Sans Regular and Bold from the official archived Noto font repository:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/notofonts/noto-fonts/blob/main/LICENSE

Downloaded 2026-10-18. Licensed under SIL Open Font License 1.1; included in OFL.txt.
These fonts provide Russian/Cyrillic and Latin text. This template does not render Chinese copy.
The deployment bundle manifest records SHA256 for both font files and the license.
