# 离线验证

在仓库根目录、已安装运行依赖的 Python 环境中执行：

```sh
python -B deploy/test_offline.py
```

目前共 120 项检查，覆盖登录和权限、图库与采集、生图调用边界、双语套图策划、主图四条文案及两种排字方式。测试使用临时数据库、合成图片和模拟供应商，不导入 `app.main`，不操作正式用户数据。入口会清除进程中的供应商配置并阻断外网连接。

`offline_client.py` 与 `support_client.py` 直接执行测试应用的 ASGI 请求，实际经过路由、参数验证及响应处理，不依赖 `httpx` 或 `httpx2`。两种客户端都只供测试使用；测试应用自行初始化数据库，不依赖应用生命周期启动逻辑。

这些检查不代表真实 API 当前余额、外语内容质量或浏览器视觉效果已验收。首次公网发布还应在目标 Linux 镜像中运行同样检查，再进行备份与切换。
