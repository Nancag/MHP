# MHP1.0.0 清理版

本包为2026-10-24清理后的本地项目，目录名不改变历史源码版本号。

- 已移除全部本地抠图模型、推理依赖、抠图API、工作台抠图按钮、结果对比和默认模型设置。
- 千问/DashScope外部模型调用也已移除。
- 保留原图上传、原图排版/裁切、套图文案、逐页审核和ZIP导出、已有生成历史、账户、额度、模板、调研与设置。
- 旧数据库中的抠图表、历史字段及已有结果文件仅作为历史数据保留，没有可调用的抠图接口；没有清空业务库。
- 原图本身带有透明通道时仍可正常排版，这属于普通图片处理，不会执行自动抠图。
- 部分旧文档描述的是移除前的功能，以本说明和当前代码为准。

完整解压后双击`启动MHP.bat`运行本地项目；双击`打开在线MHP.bat`访问线上网址。线上服务器不会自动同步本次本地修改。

旧Windows安装包及内置旧界面的客户端构建产物已清理。源码和必要构建工具仍保留，尚未发布新的桌面安装包。

2026-10-25更新：MKHP已加入商品采集、浏览器插件导入、俄文等目标语言＋中文翻译、Word/JSON导出、按来源管理素材和费率成本计算；PTMD已接入GPT Image 2商品参考图生成。后端文本/图像通过curl调用，密钥不得放入前端。

本次文件夹清理前83项离线回归通过；测试源码、一次性测试脚本和测试数据已备份归档后从工作目录删除，并调整Docker构建以免引用缺失的tests目录。具体清单与兼容性限制见 `docs/目录检查与清理-20261025.md`。历史备份、旧发布压缩包不代表当前运行版本。
