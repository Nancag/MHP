MHP Windows 内测版 1.1.0（未签名，内置前端）

服务地址：https://118.178.92.58/
适用系统：Windows 10/11 x64，.NET Framework 4.8，Microsoft Edge WebView2 Runtime。

安装版：运行 MHP-Setup-1.1.0-x64.exe，可选择安装位置。默认安装在当前用户目录。
便携版：完整解压 ZIP 后运行 MHP 文件夹内的 MHP.exe，不能只复制单个 EXE。
缺少 WebView2 时，安装版会调用微软官方引导程序，需要联网下载运行时。
缺少 .NET Framework 4.8 时，请先从微软官方网站安装该框架。

这是在线客户端，账户、签到额度、历史和图片与同一服务器的网页共用。
首页、PTMD/MKHP界面、样式和图片资源已嵌入本机程序，不再加载服务器首页及前端脚本。
断网时可打开本机界面，登录、云端历史、图片上传及AI生成仍需要网络。
前端随客户端升级；安装客户端不会自动更新服务器代码或模型配置。
API Key、邮箱授权码、服务器数据库及抠图模型不包含在客户端内。
未登录可先查看登录页；注册时验证邮箱并设置密码；之后使用密码登录。
默认记住此设备，持久会话由服务器验证；主动退出或清理资料后需重新输入密码。
程序与普通浏览器使用独立的本机登录资料，不会自动读取浏览器账号。

图片或套图下载时会显示 Windows 保存窗口，可选择位置及取消保存。
客户端仅允许打开指定 MHP 服务内的页面，并正常验证 HTTPS 证书。
服务器不可用或证书错误时，请联系维护人员；客户端不会绕过验证。

工具栏可回到首页、刷新/重试和检查更新。自动检查新版，下载和安装前由用户确认。
卸载可在 Windows“已安装的应用”中找到“MHP 内测版”。
卸载不会删除服务器上的用户、额度、图片或历史；本机 WebView2 资料也会保留。
公共电脑使用完毕请在 MHP 内退出登录。所有文件默认使用当前 Windows 用户权限。

本安装包没有代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
遇到系统安全阻止时请交由用户自行判断或联系维护人员，不需要关闭安全软件。
正式广泛发布前仍需更多 Windows 设备验证及评估代码签名。
内测请自行确认真实邮箱登录、生成、保存位置选择和取消保存。

WebView2 SDK 授权文件见 WebView2-LICENSE.txt。
微软 WebView2 Runtime：https://developer.microsoft.com/microsoft-edge/webview2/
.NET Framework 4.8：https://dotnet.microsoft.com/download/dotnet-framework/net48

启动时及每15分钟检查签名更新信息；用户可选择是否下载和安装。
更新包经发布签名与SHA256验证；旧程序原位替换，自动清理MHP受管目录中有标记的旧更新缓存。
不会扫描或删除其他位置的个人下载、用户图片、账号资料。程序安装包仍未作Windows Authenticode签名。
