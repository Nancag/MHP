安装前了解

  1. 运行环境：需要 .NET Framework 4.8 和 Microsoft WebView2 Runtime。安装包会在缺少 WebView2 时尝试联网安装微软运行时；便携版不自动安装依赖。
  2. 内测版本：当前安装包未签名，Windows 可能显示发布者或信誉提示。请核对下载来源与 SHA256；无需关闭系统安全防护。
  3. 本机界面，云端功能：断网也能打开内置界面；登录、上传、历史及图片生成仍需网络。客户端不包含本地生成模型，现有账户可直接登录。
  4. 后续更新：首版使用手动更新。关闭客户端后再安装新版本。请使用普通浏览器下载安装包。

卸载程序会保留本机登录资料及云端数据。在共用电脑上使用后，请先退出账户。此版本仍需在不同 Windows 设备上进行内测。
