# MHP 商品采集助手 0.3.0（Edge 内测版）

无需在 MHP 粘贴商品链接。请在 Edge 浏览器地址栏打开商品页，再从地址栏右侧的“扩展”（通常是拼图图标）菜单点击“MHP 商品采集助手”。插件位于浏览器工具栏，不是 MHP 网页内的按钮。

新手流程：安装插件 → 找到浏览器扩展按钮 → 同一浏览器准备 MHP 和商品页两个标签 → 在商品页读取并发送 → 回 MHP 核对字段与图片并确认导入 → 查看采集历史和 PTMD 示例图库。电脑端 Edge 支持此流程；手机与桌面客户端内部不能运行浏览器扩展。

安装目录须包含 manifest.json、popup.html、popup.css、popup.js 、extractor.js、bridge.js 和 background.js。

1. Windows 用户可下载 MHP-Collector-Setup.exe，运行后确认“保存插件文件”，再确认打开 Edge 管理页，并复制工具提供的加载路径。工具不下载额外文件、不修改注册表、不提权、不替你确认加载扩展。也可继续手动解压 ZIP，在 Edge 地址栏输入 edge://extensions。
2. 开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择本文件所在的 mhp-collector 文件夹，不选ZIP或外层目录。
4. 确认扩展名称“MHP 商品采集助手”、版本 0.3.0，可在工具栏扩展菜单中固定。返回 MKHP 查看“插件已安装并启用（v0.3.0），可以开始采集商品。”提示；如未检测到，请刷新页面并点击“重新检测”。下载 ZIP 或关闭教程不会被认定为安装成功。
5. 在同一个 Edge 中打开 https://118.178.92.58 或 http://127.0.0.1:5173，登录MHP并进入MKHP。只保留一个MHP标签页。
6. 另开商品页，自行登录并处理验证，选择规格、展开参数，等待页面加载。
7. 点击插件 → 读取当前商品页 → 核对候选字段 → 发送到已打开的MKHP预览。
8. 在MHP核对、编辑字段，逐张勾选最多20张图片，确认后导入。图片按商品来源网址归档，可在PTMD示例图库中使用。

支持：item.taobao.com、detail.tmall.com 的含 id 商品页，以及 mobile.yangkeduo.com、mobile.pinduoduo.com 的含 goods_id 商品页。短链接需先在浏览器正常跳转到商品详情页。本版不保证平台所有页面版本可读；未识别字段留空，不能编造尺寸或材质。

权限：activeTab（点击时临时访问当前页）、scripting（提取商品内容及发送预览）、两个本机MHP地址与 https://118.178.92.58 的页面访问权限。没有cookies、密码、订单、支付或全网站持久访问权限；插件内没有AI密钥。不要求把电商平台Cookie上传到服务器。

注意：候选图可能含推荐商品，必须人工筛选。显示缩略图会访问图片网址；确认导入后，MHP后端才会下载所选图片。价格受规格与优惠影响，需核对。图片不可公开下载时会显示失败，不会自动重试。

更新：保留安装目录，在扩展管理页点击“重新加载”。删除目录会使插件失效。卸载：扩展管理页点击“删除”。本版未上架商店，支持上述云端和本机地址。旧版用户需下载新版覆盖安装目录，重新加载扩展，并确认新增的云端地址权限。插件禁用或删除后，MKHP下次检测会显示“未检测到插件”；安装状态只代表页面连接，不保证所有商品页可采集。

完整教程：https://118.178.92.58/mhp-collector-guide.html

首次进入MKHP显示安装教程，关闭后按当前账号和浏览器记忆。可随时从“安装插件与详细教程”打开。清除站点数据会重置提醒。

Windows 辅助工具将本版本插件保存在 %LOCALAPPDATA%\MHP\Collector\0.3.0-<包校验标识>\mhp-collector；请保留此目录。重复运行会核对已保存文件，不覆盖修改过的文件。新版目录与旧版分开，需在 Edge 手动移除旧扩展再加载新版，以免重复安装。辅助工具尚未签名，若被系统拦截，可取消并使用 ZIP，不需要关闭系统防护。

0.3.0 修复页面参数分隔符与多行尺寸匹配，支持 JSON-LD 包裹尺寸参数和带单位的尺寸值，优先保留可见规格价格。插件采集不调用服务器静态网页读取；确认导入后服务器只访问所选图片网址。
